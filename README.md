# VEREDIKT

**División de Homicidios & Forense**

> Un caso. Pistas. Sospechosos. Y una sola pregunta: **¿podés resolverlo?**

**VEREDIKT** es un juego de investigación detectivesca con estética *noir*. En cada partida se genera un caso único —víctima, escenario, sospechosos y pistas— y te toca a vos recorrer el expediente, interrogar, atar cabos y emitir el veredicto final.

No hay dos casos iguales: la historia la arma una IA, así que cada investigación es distinta y está llena de coartadas, contradicciones y algún que otro secreto bien guardado.

---

## ¿Cómo se juega?

1. **Entrá a la mesa de entrada.** Vas a ver el escritorio del detective con las carpetas del caso.
2. **Abrí un caso nuevo** (`Nuevo`) y elegí las características. La IA redacta el expediente con víctima, sospechosos y escenas.
3. **Investigá.** Visitá locaciones, revisá la evidencia y tomá notas en el panel del detective.
4. **Interrogá a los sospechosos.** Hacé las preguntas que quieras: las coartadas pueden sostenerse… o derrumbarse.
5. **Acusá.** Cuando estés seguro, señalá al culpable y fundamentá tu veredicto.
6. **Descubrí logros, jugá casos de la comunidad** (importá expedientes en `.json`) **o competí en el modo cooperativo.**

> No hace falta saber nada de programación. Solo necesitás una **clave de API** de un proveedor de IA (se configura en ⚙️ *Ajustes* y se guarda únicamente en tu navegador).

---

## Características

- 🕵️ **Casos generados por IA** — historia, pistas y sospechosos distintos en cada partida.
- 💬 **Interrogatorios libres** — preguntá lo que quieras, cuando quieras.
- 🗂️ **Panel de detective** — notás, relacionás y seguís tu propia línea de investigación.
- 🏆 **Logros y condecoraciones** — desbloqueables al resolver (y al descubrir ciertos misterios ocultos).
- 🤝 **Modo cooperativo** — resolvé en equipo y compará puntajes.
- 📥 **Casos de la comunidad** — importá expedientes `.json` y jugá casos creados por otros.
- 🔐 **Tu clave, tu navegador** — la API key nunca sale de tu equipo; la elección de proveedor es 100% tuya.

## Requisitos

- [Node.js](https://nodejs.org/) 18 o superior.
- Una clave de API de alguno de los proveedores compatibles (podés probar varios desde la app).

## Ejecutar en local

```bash
# instalar dependencias
npm install

# levantar el servidor de desarrollo
npm run dev

# compilar para producción
npm run build

# previsualizar la versión compilada
npm run preview
```
